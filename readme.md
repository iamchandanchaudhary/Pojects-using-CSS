## 📂 Projects Overview

### 🛒 Amazon Clone
A responsive clone of Amazon's e-commerce homepage featuring:
- Hero section with promotional banners
- Product grid layout with hover effects
- Navigation bar with search functionality
- Footer with multiple link sections

### 🎬 Netflix Clone
A pixel-perfect recreation of Netflix's landing page including:
- Video background sections
- Accordion FAQ component
- Responsive grid layouts
- Custom SVG icons and animations

### 🔲 Border Animations
Creative CSS border animation effects:
- Animated gradient borders
- Moving border effects
- Interactive hover states

### 🎭 Background Animations
A collection of mesmerizing background animations:
- **Circle Animation 1** - Expanding circle effects
- **Circle Animation 2** - Rotating circle patterns
- **Dropping Line Animation** - Cascading line effects
- **Square Animation** - Geometric square transitions

### 🃏 Cards
Various card component designs:
- **Animated Cards** - Cards with colorful and moving borders
- **Grid Cards** - Responsive grid-based card layouts
- **Normal Cards** - Clean, minimal card designs

### 📜 Scroll Animations
Scroll-triggered animation effects:
- Fade-in on scroll
- Slide animations
- Parallax effects

### 📋 CV / Resume
HTML/CSS resume templates:
- Multiple layout variations
- Print-friendly designs
- Professional styling

### 🧭 Navbar
Modern navigation bar component:
- Hamburger menu for mobile
- Dropdown navigation
- Smooth transitions and hover effects

### 💬 Tooltip
Custom tooltip implementations:
- Technology stack tooltips (React, Node.js, MongoDB, Express)
- Animated hover effects
- SVG icon integration

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/Projects-using-CSS.git
   ```

2. **Navigate to any project folder**
   ```bash
   cd Projects-using-CSS/Amazon-Clone
   ```

3. **Open in browser**
   - Simply open the `index.html` file in your preferred browser
   - Or use a live server extension for better experience
